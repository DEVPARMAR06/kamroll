# Changelog

## 0.1.0 (unreleased)

First public version.

- Back up an iPhone to an SSD at original quality, over USB, resumable and crash-safe, with SHA-256 verification.
- Dated folders from the photo or video itself; trips from GPS with offline place names; rename, add to, take from, create and delete trips; optional filing of trips into folders.
- Review screen with tags and reasons; Health screen (compare phone and SSD, re-read every file, repair queue).
- Optional smart tags through a local Ollama.
- Old-folder tools: compare, import, adopt, consolidate, relocate.
- Rust engine (about 8 MB) with a command line; Windows installer and macOS app built by CI.
