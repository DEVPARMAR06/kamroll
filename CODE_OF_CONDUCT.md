# Code of conduct

Be kind and be useful. Assume good faith, disagree about ideas rather than people, and keep discussion on topic. Harassment, insults and personal attacks are not welcome.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block people who keep breaking them. To report a problem, contact the maintainer through a private GitHub message or the repository's Security tab.

This is a short version of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which applies in full.
